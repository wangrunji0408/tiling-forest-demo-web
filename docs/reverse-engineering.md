# 逆向记录与验证

## 来源与资源结构

原版 demo 使用 OpenSiv3D。`tiling_forest.exe` 是 Windows PE，可通过 `FILE` 类型的资源表读取内嵌资源。未修改原始二进制文件，也未绕过 DRM。

提取脚本保留原始文件内容，路径转换为小写：

- `WORLD/FOREST/MAP/FIELD.JSON`：完整地图，35 个不规则区域、区域外固定图块、起点 `(-2,22)`。
- `TILE.JSON`：每种图块的贴图坐标、四边地形、道路端口、树桩朝向及花朵状态贴图。
- `PALETTE.JSON`：36 档奖励顺序。初始为横向道路；每首次完成一个区域增加一种图块。
- `RULE.JSON`：区域填充 / 道路连通 / 树桩配对；N-6 通关；森林完全完成。
- `EVENT.JSON`：原版教程触发点与结局条件，作为玩法分析依据；本版没有完整移植这些演出。
- `world/forest/guide`、`text`：原版多语言规则与提示。
- 图片 atlas 采用 32×32 单元。树木由地面与前景两层组成。

## 实现约定

`engine.js` 保留原版坐标、区域 ID、图块 ID 和奖励顺序。邻边同时匹配地形与道路存在性。`road*` 表示空地连通，参与探索和区域道路连通，但不传播花朵。

到达的区域和外部道路永久记录。区域完成状态按当前布局重新判定，首次完成的奖励不会因撤销而失去。树桩必须相向、相距两格，中间有道路；道路连通分量包含恰好一对树桩时开花。

浏览器存档采用独立键值与版本，不写入 Steam 存档。导入原版进度只读取布局、到达的道路和区域历史；Steam 账号标识不会进入网页版存档。

## 验证

- 12 项 Node 测试覆盖地图引用、开局解锁、W-1 / W-2 奖励顺序、非法放置、地形边缘、撤销重做、保存恢复、树桩配对、花朵枯萎与停止传播、道路断开、区域布局恢复。
- 对本机已有原版存档做只读校验：35 个区域均通过本实现的区域完成条件。个人存档不包含在仓库内。
- 浏览器实际点击完成 W-1，确认 W-2 解锁及左上弯道奖励；撤销 / 重做与刷新恢复均通过。
- 地图 / 贴图 / 音频来自原始资源。由于原版原生窗口的辅助功能接口超时，尚未完成原版 UI 逐像素截图比对；不声称界面或所有边界行为 100% 一致。

## CrossOver 启动修复

本机原版启动曾报 `0xc0000142`。日志定位为 `winemetal.dll` 初始化时找不到对应 `winemetal.so`。已为 `tiling_forest.exe` 单独设置 Wine `DllOverrides` 的 `d3d11`、`dxgi` 为 `builtin`，随后用户确认可正常打开。此设置未修改其他游戏的专用配置。
